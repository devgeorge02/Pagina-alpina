# Página Alpina

Sitio web estático de ejemplo para la página "Pagina-alpina".

## Descripción

Proyecto estático en HTML, CSS y JavaScript que contiene páginas públicas y una sección de administración. Incluye archivos estáticos (imágenes, videos, estilos y scripts) organizados en carpetas por funcionalidad.

## Características

- Páginas públicas: inicio, contacto, historia, productos.
- Panel de administración básico con páginas en `pages/admin/`.
- Estructura sencilla para desplegar como sitio estático.

## Estructura del repositorio

- [index.html](index.html) — página principal.
- [css/](css/) — estilos (admin y público).
- [js/](js/) — scripts JS principales y admin.
- [pages/](pages/) — HTML de páginas públicas y admin.
- [img/](img/) — imágenes y logos.
- [videos/](videos/) — recursos de video.
